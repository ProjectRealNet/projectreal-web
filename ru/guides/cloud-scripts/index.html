Гайды

Cloud scripts

Управляйте одними и теми же cloud файлами в приложении Real и в Dashboard. Используйте Dashboard, когда нужны детали файла, расход хранилища, лимит и более крупный просмотр кода.

Гайды

Before you start

Все гайды

Cloud Scripts можно управлять прямо в редакторе приложения Real.

Dashboard показывает расход хранилища, лимит, папки, время и детали для тех же cloud файлов.

Используйте raw view, copy raw, download или копирование пути при переносе кода в другой редактор.

Гайды

Шаги

1.Используйте Cloud Scripts в Real

Откройте редактор в приложении Real и используйте корень Cloud Scripts, чтобы создавать папки, сохранять скрипты, открывать файлы, переименовывать элементы или удалять старые скрипты, не выходя из Real.

2.Проверяйте те же файлы в Dashboard

Откройте раздел Cloud в Dashboard, чтобы видеть папки, имена файлов, расход хранилища, лимит, время обновления и детали файлов. Это удобно, когда нужно проверить файлы вне приложения.

3.Следите за использованием и переносите код

Dashboard показывает, сколько cloud хранилища использует аккаунт. Raw view, copy raw, download raw и копирование пути помогают при отладке скрипта или переносе в другой редактор.

Гайды

Похожие гайды

Installation Установите Real с правильной подготовкой Windows Security, нужными рантаймами Windows, официальным RealSetup.exe и проверками загрузки в браузере, которые могут появиться. Create a Real account Создай аккаунт Real через Discord или email. Выбери один способ, выполни только нужные шаги и подтверди аккаунт перед использованием Real. Привязать Discord Подключи Discord к существующему аккаунту Real, чтобы роль Real User и доступ к поддержке назначались правильно.
