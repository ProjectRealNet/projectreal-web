Гайды

Multi Instance

Открывай несколько клиентов Roblox и запускай скрипты на выбранных аккаунтах.

Гайды

Before you start

Все гайды

Используй отдельный аккаунт Roblox для каждого клиента.

Перед inject используй версию Roblox с меткой Supported.

Инжекть только клиенты, которые должны получать скрипты.

Гайды

Шаги

01Включи Multi Roblox

Открой Account Manager -> Options и включи Multi Roblox. Оставь Join Delay включенным или задай небольшую задержку, если запускаешь много аккаунтов сразу.

02Добавь аккаунты Roblox

Добавь каждый аккаунт Roblox, который хочешь использовать. Multi Instance требует отдельные аккаунты Roblox, а не один и тот же аккаунт два раза.

03Создай группу и запусти все

Открой Multi Launch, создай группу с нужными аккаунтами, выбери игру и нажми Launch all.

04Выбери поддерживаемую версию Roblox

Когда Real спросит, какую версию Roblox использовать, выбери версию с меткой Supported. Дождись, пока каждый клиент Roblox зайдет в игру.

05Нажми Inject

Открой Editor Tab и нажми Inject. Real откроет панель Clients, где можно выбрать, какие запущенные клиенты Roblox нужно инжектить.

06Инжектни нужные клиенты

В панели Clients нажми Inject для каждого аккаунта Roblox, который хочешь использовать. Оставь Execute target включенным на клиентах, которые должны получать скрипты.

07Проверь статус injected

Подожди, пока каждый выбранный клиент покажет Injected. Если один клиент не инжектится, сначала исправь его, а потом запускай скрипты на всех аккаунтах.

08Найди и запусти скрипт

Открой Script Hub, выбери скрипт и нажми Execute. Также можно вставить свой скрипт в Editor Tab и запустить его оттуда.

09Проверь результат в Roblox

Оба инжектнутых клиента должны показать результат скрипта в Roblox. Если реагирует только один, проверь панель Clients и Execute targets еще раз.

Похожие гайды

Installation Установите Real с правильной подготовкой Windows Security, нужными рантаймами Windows, официальным RealSetup.exe и проверками загрузки в браузере, которые могут появиться. Create a Real account Создай аккаунт Real через Discord или email. Выбери один способ, выполни только нужные шаги и подтверди аккаунт перед использованием Real. Привязать Discord Подключи Discord к существующему аккаунту Real, чтобы роль Real User и доступ к поддержке назначались правильно.
