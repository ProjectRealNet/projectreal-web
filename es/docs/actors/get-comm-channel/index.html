Actors

get_comm_channel

Busca un channel ID en el communication channel list y devuelve la BindableEvent Instance almacenada.

Sintaxis

get_comm_channel(channelId: number): Instance | nil

Argumentos

NombreTipoDescripción
channelIdnumberChannel ID que se convierte con integer conversion y se busca en el communication channel list.

Retornos

NombreTipoDescripción
eventInstance | nilBindableEvent Instance almacenada para el channel ID, o nil cuando el ID no está presente en communication channels.

Descripción

Busca un channel ID en el communication channel list y devuelve la BindableEvent Instance almacenada. El primer argument debe ser number y se convierte con integer conversion antes del lookup. Si no existe entry para ese ID, la function devuelve nil.

Llamalo con 1 parametro(s): channelId. La tabla de argumentos explica que valores son obligatorios y cuales refinan el comportamiento.

Devuelve event (Instance | nil). Usa la tabla de retornos para separar valores correctos, resultados nil y errores recuperables.

Ejemplo

Look up the BindableEvent Instance stored for a communication channel ID.

local channelId = create_comm_channel()
local event = get_comm_channel(channelId)

print(event)
