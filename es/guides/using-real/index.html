Guías

Usar Real

Inicia la version compatible de Roblox, inyecta desde Editor y ejecuta scripts desde Script Hub o tu propio codigo.

Guías

Before you start

Todas las guías

Inicia Roblox desde la opcion de version compatible en Real antes de pulsar Inject.

Usa Script Hub si quieres scripts integrados para juegos que Real ya lista.

Usa Editor Tab si quieres pegar y ejecutar tu propio codigo.

Guías

Pasos

01Inicia la version compatible de Roblox

Abre Real, ve a Real -> Settings -> Roblox Tab e inicia desde alli la version compatible de Roblox. Luego entra al juego donde quieres usar Real.

02Inyecta desde Editor Tab

Abre Editor Tab y pulsa Inject. Si falla la inyeccion, detente y abre Injection troubleshooting antes de probar arreglos al azar.

03Ejecuta un script

Despues de inyectar, abre Scripts Tab para explorar entradas de Script Hub para juegos compatibles y ejecutarlas directamente. Tambien puedes pegar un script de otra fuente confiable en Editor Tab y pulsar Execute. Si la ejecucion funciona pero un script falla, abre El script no funciona.

Installation Instala Real con la preparacion correcta de Seguridad de Windows, las runtimes necesarias de Windows, el RealSetup.exe oficial y las comprobaciones de descarga del navegador que pueden aparecer.
