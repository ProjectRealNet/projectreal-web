가이드

Real 업데이트

설치된 버전을 확인하고 최신 릴리스와 비교한 다음, Real을 완전히 종료한 뒤 다시 열어 업데이트하세요.

가이드

Before you start

모든 가이드

다시 열기 전에 시스템 트레이에서 Real을 완전히 종료해야 합니다.

Release Notes에서 최신 공개 버전을 확인하세요.

Updating Real이 표시되는 동안 업데이트 창을 닫지 마세요.

가이드

단계

01버전 확인

Real을 열고 Home 탭의 Real Version을 확인하세요. 그런 다음 문서의 Release Notes를 열어 가장 최신 버전과 비교하세요.

02Real 완전히 종료하기

Real이 시스템 트레이에만 닫혀 있으면 다시 열 때 현재 앱 창만 표시됩니다. 트레이 메뉴를 열고 Real을 우클릭한 뒤 업데이트 전에 Quit을 선택하세요.

03Real 정상적으로 열기

Real을 완전히 종료한 뒤 Windows 검색이나 바로가기로 Real을 여세요. 앱이 열리기 전에 업데이트가 실행됩니다. 완료될 때까지 업데이트 창을 닫지 마세요.

가이드

관련 가이드

Installation 올바른 Windows Security 준비, 필요한 Windows 런타임, 공식 RealSetup.exe, 브라우저 다운로드 확인 절차를 따라 Real을 설치합니다. Create a Real account Discord 또는 이메일로 Real 계정을 만드세요. 한 가지 방법을 선택하고 해당 단계만 진행한 뒤 Real을 사용하기 전에 계정을 확인하세요. Discord 연결 기존 Real 계정에 Discord를 연결해 Real User 역할과 지원 접근 권한이 올바르게 지급되도록 합니다.
