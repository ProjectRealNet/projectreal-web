쿠키 정책.

브라우저에 저장되는 것. 그 역할. 해제하는 방법.

이 쿠키 정책은 Project Real이 Real 공식 도메인(projectreal.gg, projectreal.live, projectreal.net, realest.gg) 및 api.projectreal.gg 같은 API 하위 도메인에서 사용하는 쿠키를 설명합니다. 이는 당사의 개인정보.

1. 요약

현재 로그인, CSRF 보호, 쿠키 환경설정 및 Cloudflare 보안을 위해 필수 쿠키를 사용합니다. 2026년 5월 현재 Real 공식 도메인에서 분석, 광고 또는 마케팅 쿠키를 사용하지 않습니다.

법적 근거: GDPR 유형의 법률이 적용되는 경우, 아래에 나열된 쿠키 및 관련 개인 데이터 처리는 계약 이행(계정 로그인, 라이선스 등록, 계정 관리)과 IT 보안, 사기 방지, CSRF 보호, 남용 방지를 위한 정당한 이익을 근거로 합니다. 비필수 쿠키는 해당 지역에서 요구되는 경우 사용 전 동의가 필요합니다.

2. Project Real이 설정하는 쿠키

이름 도메인 목적 기간 속성 유형
account_session projectreal.gg 로그인 상태를 유지하고 API가 인증된 계정 요청을 검증할 수 있도록 합니다. 기본 24시간; "로그인 상태 유지" 또는 Discord 로그인 사용 시 30일 HttpOnly Secure SameSite=Lax 필수
account_csrf projectreal.gg CSRF로부터 계정 작업을 보호합니다. Domain=projectreal.gg을 사용하기 때문에 브라우저 DevTools에서 메인 사이트와 API 서브도메인 양쪽에 표시될 수 있습니다. 이는 도메인 범위의 단일 쿠키입니다. account_session 기간과 동일 JS-readable Secure SameSite=Lax 필수
real_cookie_consent projectreal.gg 쿠키 환경설정을 저장하여 방문마다 배너가 표시되지 않도록 합니다. 1년 JS-readable Secure SameSite=Lax 필수

3. 제3자 쿠키

이름 Provider 목적 기간 속성 유형
cf_clearance Cloudflare 브라우저가 보안 챌린지를 통과했음을 Cloudflare에 알려 모든 요청마다 챌린지가 반복되지 않도록 합니다. Cloudflare 챌린지 구성에 의해 설정되며, Cloudflare가 클리어런스를 수락하는 동안만 유효 Secure SameSite=None Partitioned 필수
__cf_bm Cloudflare 정상 트래픽과 자동화된 남용을 구별하는 데 사용되는 Cloudflare 봇 관리 쿠키. 비활동 30분 HttpOnly Secure SameSite=None 필수

Cloudflare의 전체 쿠키 문서 및 데이터 처리 방식은 Cloudflare Cookies 및 Cloudflare Privacy Policy.

4. 쿠키 보안

HttpOnly: JavaScript가 쿠키를 읽을 수 없습니다. account_session에 사용됩니다.

Secure: 브라우저가 HTTPS를 통해서만 쿠키를 전송합니다.

SameSite=Lax: 일반적인 로그인/탐색 흐름을 유지하면서 대부분의 크로스 사이트 요청 공격을 차단하는 데 도움이 됩니다.

JS-readable: 프론트엔드에서 이 쿠키를 읽을 수 있습니다. CSRF 토큰 폴백 및 환경설정 저장에만 사용됩니다.

5. 필수 쿠키에 동의가 필요 없는 이유

쿠키 동의 규칙이 있는 지역에서는 비필수 쿠키에 일반적으로 동의가 필요합니다. 위에 나열된 쿠키는 로그인, 계정 보안, 환경설정 저장, 봇 보호를 제공하므로 필수 쿠키입니다. 향후 분석, 광고, 또는 기타 비필수 쿠키를 추가하는 경우, 필요한 지역에서는 사전에 동의를 요청할 것입니다.

6. 쿠키 관리 및 삭제

브라우저에서 언제든지 쿠키를 확인, 차단, 삭제할 수 있습니다. 필수 쿠키를 차단하면 로그인, 대시보드 접근, 광고 단계 등록이 작동하지 않습니다.

  • Chrome / Edge: 설정 > 개인정보 및 보안 > 쿠키 및 기타 사이트 데이터 > 모든 사이트 데이터 및 권한 보기
  • Firefox: 설정 > 개인정보 및 보안 > 쿠키 및 사이트 데이터 > 데이터 관리
  • Safari: 설정 > 개인정보 보호 > 웹사이트 데이터 관리
  • Mobile browsers: 브라우저 설정 앱에서 브라우저 데이터 또는 사이트별 데이터를 지우십시오.

8. 제3자 광고 벽 제공업체

무료 라이선스 키는 Work.ink와 같은 광고 벽 제공업체를 사용할 수 있습니다. Project Real을 떠나 해당 흐름에 진입하면 해당 업체의 쿠키 및 개인정보 정책이 적용됩니다: work.ink.

9. 본 정책의 변경

Project Real은 웹사이트, 백엔드, 또는 법적 요구 사항이 변경될 때 쿠키 정책을 업데이트합니다. 중요한 변경 사항은 Discord 서버를 통해 공지됩니다. 최신 버전은 항상 projectreal.gg/cookies.
