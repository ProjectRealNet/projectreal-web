FAQ

자주 묻는 질문

Real은 무료인가요?

네. Real은 매일 제공되는 무료 키로 사용할 수 있습니다. Plus와 Pro 키는 인증된 리셀러를 통한 선택형 유료 접근이며, 광고 단계 없이 추가 혜택을 제공합니다.

Real은 어디서 다운로드하나요?

projectreal.gg의 공식 Download 페이지를 사용하세요. 재업로드된 설치 파일, 수정된 압축 파일, DM으로 받은 파일은 피하세요.

Plus와 Pro는 어떻게 작동하나요?

Plus와 Pro는 구독이 아니라 라이선스 키로 등록합니다. 등록한 Real 계정에 접근 시간이 추가되고 플랜 혜택이 해제됩니다.

새 PC에서 Real을 사용할 수 있나요?

네. Dashboard 또는 앱 로그인 중 기존 기기를 재설정한 뒤 새 PC에서 로그인하세요. 기기 재설정 쿨다운은 플랜에 따라 달라집니다.

Windows가 설치 파일을 차단하는 이유는 무엇인가요?

Windows 또는 브라우저 보안이 보호된 설치 파일에 대해 경고할 수 있습니다. 설치 가이드에서 Windows Security를 준비하고 공식 RealSetup.exe를 유지하는 방법을 설명합니다.

지원은 어디서 받을 수 있나요?

Real Discord에 참여하고, 필요하면 계정을 연결한 뒤 스크린샷이나 로그와 함께 지원 티켓을 열면 팀이 더 빠르게 도와드릴 수 있습니다.
