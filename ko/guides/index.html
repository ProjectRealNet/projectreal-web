가이드 둘러보기

15 가이드
Installation 5분 읽기 올바른 Windows Security 준비, 필요한 Windows 런타임, 공식 RealSetup.exe, 브라우저 다운로드 확인 절차를 따라 Real을 설치합니다. Create a Real account 3분 읽기 Discord 또는 이메일로 Real 계정을 만드세요. 한 가지 방법을 선택하고 해당 단계만 진행한 뒤 Real을 사용하기 전에 계정을 확인하세요. Discord 연결 2분 읽기 기존 Real 계정에 Discord를 연결해 Real User 역할과 지원 접근 권한이 올바르게 지급되도록 합니다. Real 계정 삭제 3분 읽기 계정 삭제를 요청하고 이메일로 확인한 뒤 30일 복구 기간을 이해하세요. Free key system 3분 읽기 Use the free key option on Pricing, complete two ad steps, and receive 24 hours on your Real account. Real 사용하기 4분 읽기 지원되는 Roblox 버전을 실행하고 Editor에서 Inject한 뒤 Script Hub 또는 직접 작성한 코드를 실행합니다. Auto Execute 4분 읽기 Roblox가 게임에 들어간 뒤 선택한 스크립트를 자동으로 실행합니다. Roblox 다운그레이드 3분 읽기 Real이 이전 빌드를 필요로 할 때 지원되는 Roblox 버전을 실행합니다. Real 업데이트 4분 읽기 설치된 버전을 확인하고 최신 릴리스와 비교한 다음, Real을 완전히 종료한 뒤 다시 열어 업데이트하세요. Multi Instance 6분 읽기 여러 Roblox 클라이언트를 열고 선택한 계정에서 스크립트를 실행합니다. 기기 또는 HWID 재설정 2분 읽기 Real 계정을 다른 PC로 옮기거나 현재 기기 연결을 해제합니다. Roblox HWID Spoofer와는 다른 기능입니다. HWID Spoofer 4분 읽기 Roblox 기기 ID를 임시로 새로고침합니다. Cloud scripts 3분 읽기 Real 앱과 Dashboard에서 같은 클라우드 파일을 관리할 수 있습니다. 파일 세부 정보, 저장소 사용량, 할당량, 더 큰 코드 뷰어가 필요하면 Dashboard를 사용하세요. Real MCP 설정 4분 읽기 Real을 Claude Code, Claude Desktop, Cursor, Codex, Grok, Antigravity, Gemini CLI, OpenCode, LM Studio, OpenClaw 또는 ZCode에 연결해 AI가 주입된 Roblox 클라이언트와 작업할 수 있게 합니다. 라이선스 구매 4분 읽기 인증된 reseller에게 Plus 또는 Pro를 구매하고 license key를 받은 뒤 올바른 Real 계정에서 redeem하세요.
