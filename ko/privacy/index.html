개인정보 처리방침.

수집하는 것. 수집하지 않는 것. 사용 방법.

Real은 Real 공식 도메인(projectreal.gg, projectreal.live, projectreal.net, realest.gg), Real 계정, 라이선스 등록, 다운로드 및 Real 소프트웨어를 운영합니다. 이 정책은 당사가 처리하는 개인정보와 그 이유를 설명합니다.

요약: 당사는 계정 운영, 라이선스 확인, 서비스 보안, 지원 제공 및 악용 방지를 위해 데이터를 사용합니다. 개인정보를 판매하지 않으며, 2026년 5월 현재 Real 공식 도메인에서 분석 또는 마케팅 쿠키를 사용하지 않습니다.

1. 수집하는 데이터

  • Account data: 계정 데이터: 사용자명, 이메일 주소, 비밀번호 해시, 이메일 인증 상태, 비밀번호 재설정 기록, 계정 상태, 계정 잔액/만료일, 생성 시각, 마지막 로그인, 지원 및 남용 방지를 위한 제한된 계정 이력.
  • License and device data: 라이선스 및 기기 데이터: 라이선스 기록, 등록 상태, 만료일, 해당 시 리셀러 출처, HWID 해시, 기기 공개 키, 키 보호 수준, 선택적 기기 레이블, 마지막 확인 시각, 폐기 상태.
  • Discord and support data: Discord 및 지원 데이터: Discord ID, 사용자명, 아바타 URL, Discord OAuth가 반환한 이메일, 임시 OAuth/설정 토큰, 지원에 보낸 메시지 또는 세부 정보.
  • Security data: 보안 데이터: IP 주소, 사용자 에이전트, 요청 메타데이터, 가용 시 Cloudflare 국가/보안 신호, 속도 제한 상태, 감사 로그, 보안 이벤트.

Project Real은 귀하의 스크립트, 개인 파일, 브라우저 기록, 또는 기기의 무관한 콘텐츠를 의도적으로 읽지 않습니다.

2. 사용 목적

  • 계정 생성, 이메일 인증, 비밀번호 재설정, 로그인 상태 유지.
  • 키 등록, 라이선스 검증, 계정 잔액 관리, 기기 제한 적용.
  • 사기, 키 남용, 계정 탈취 시도, 봇 트래픽, 보안 사고 탐지.
  • Discord 로그인/연동, 지원, 트랜잭션 이메일, 관리자 조치, 감사 추적 운영.
  • 약관 을 시행하고 Real, 사용자, 서비스를 보호합니다.

3. 법적 근거

GDPR 유형의 법률이 적용되는 경우, Project Real은 계정 및 라이선스 기능에는 계약 이행을, 보안 및 사기 방지에는 정당한 이익을, 선택적 기능 또는 향후 비필수 쿠키에는 동의를, 법률에 따라 기록을 보관해야 하는 경우에는 법적 의무를 근거로 합니다.

4. 쿠키

Project Real은 로그인, CSRF 보호, 쿠키 환경설정, Cloudflare 봇 보호를 위해 필수 쿠키를 사용합니다. 선택적 기능 저장은 귀하가 허용한 경우에만 사용됩니다. 전체 쿠키 목록은 쿠키.

5. 데이터 공유

개인 데이터를 판매하거나 광고주와 공유하지 않습니다. 호스팅/보안 제공업체, 트랜잭션 이메일 제공업체, Discord OAuth, 해당 흐름을 위해 사이트를 떠날 때의 광고 단계 제공업체, 법적으로 요구되는 경우 법적 기관, 사업 양도와 관련된 경우 등 Real의 운영, 보안, 지원에 필요한 경우에만 데이터를 공유합니다.

6. 보존 기간

계정 및 기기 기록은 계정이 활성 상태인 동안 보관됩니다. 삭제된 계정은 먼저 보관되었다가 삭제 처리 시 영구 삭제됩니다. 단기 인증, 재설정, OAuth, 설정, 기기 챌린지, 런치 토큰 기록은 흐름에 따라 약 60초에서 24시간 내에 만료됩니다. 감사 로그, 보안 로그, 라이선스 이력, 분쟁 기록, 백업은 보안, 사기 방지, 지원, 법적 준수, 백업 보존 주기가 필요한 경우 더 오래 보관될 수 있습니다. If you confirm account deletion from the dashboard, we first disable your account for 30 days. During that period you can restore it by signing in again. After that, we permanently delete account data unless legal retention duties or security records require longer storage.

Reseller portal and automated key sales

If you use the reseller portal, we process reseller profile fields such as public store links, Discord details, social links, avatar and banner URLs, portal login/session metadata, payment metadata, webhook audit records, and license/key prefix history. Public reseller listings may show profile details and availability derived from unredeemed keys.

Raw key bundles are not sent by email. Paid order bundles are stored encrypted for a limited download window and then removed, while license IDs, key prefixes, payment, tax, fraud-prevention, and security records may be retained for as long as they are needed for legal, accounting, dispute, and platform security purposes.

7. 보안

Project Real은 HTTPS, HttpOnly 세션 쿠키, CSRF 보호, 속도 제한, Cloudflare 보안 제어, 비밀번호 해싱, 기기 공개 키, 단기 토큰, 감사 로그를 사용합니다. 완벽히 안전한 시스템은 없습니다. 브라우저 개발자 콘솔에 명령어, 쿠키, CSRF 토큰, 일회용 코드를 절대 붙여넣지 마십시오.

8. 귀하의 권리

거주 지역에 따라 개인 데이터의 특정 처리에 대해 접근, 수정, 삭제, 내보내기, 제한, 이의 제기 권리가 있을 수 있습니다. 동의가 적용되는 선택적 기능에 대한 동의를 철회할 수도 있습니다. 문의: support@projectreal.gg; 신원 확인이 필요할 수 있습니다.

9. 제3자 서비스

Project Real은 Cloudflare, Resend, Discord, Work.ink, 리셀러 페이지와 같은 제3자 서비스를 사용하거나 연결합니다. 이들 서비스가 직접 데이터를 처리하는 경우 각자의 정책이 적용됩니다.

10. 아동 및 국제 이용

Real은 만 13세 미만 아동을 대상으로 하지 않으며, 만 13세 미만 아동의 데이터를 의도적으로 수집하지 않습니다. Project Real 및 제공업체는 법적 이전 메커니즘을 사용하여 귀하의 국가 이외의 국가에서 데이터를 처리할 수 있습니다.

11. 변경 및 문의

Project Real은 projectreal.gg/privacy. 에 새 버전을 게시하여 본 방침을 업데이트할 수 있습니다. 개인정보 관련 문의는 support@projectreal.gg 또는 당사 Discord.
