ライセンスを購入

認証済み reseller から Plus または Pro を購入し、license key を受け取り、正しい Real アカウントで redeem します。

ガイド

Before you start

すべてのガイド

利用可能な key を持つ認証済み seller を探すには Resellers を使います。

支払い前に 7 日なら Plus、30 日なら Pro を選びます。

ライセンス時間を受け取る Real アカウントでサインインした状態で key を redeem します。

ガイド

手順

01Plus または Pro を選ぶ

Plus は Real アクセス 7 日分と Priority support を追加します。Pro は 30 日分、High priority support を追加し、長く使う場合に向いています。どちらの paid license も full executor、Script Hub access、ad-steps なし、Pricing に表示されている paid account benefits を有効にします。

02認証済み reseller から購入

Resellers を開き、stock がある表示中の seller を選びます。Reseller は profile が公開、有効化され、利用可能な key がある場合だけ表示されます。ランダムな Discord メッセージや偽 store は避けてください。

03License key を redeem

購入後、時間を追加したい Real アカウントにサインインします。Pricing redeem セクションまたは Dashboard subscription セクションで key を redeem します。ライセンス時間はそのアカウントに追加されます。

ガイド

関連ガイド

Installation Windows Security の準備、必要な Windows ランタイム、公式の RealSetup.exe、表示される場合があるブラウザのダウンロード確認を通して Real をインストールします。 Create a Real account DiscordまたはメールでRealアカウントを作成します。方法を1つ選び、その方法に合う手順だけを進め、Realを使う前にアカウントを確認してください。 Discord を連携する 既存の Real アカウントに Discord を接続して、Real User ロールとサポートアクセスが正しく付与されるようにします。
