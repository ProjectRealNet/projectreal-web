Khắc phục sự cố

Khắc phục sự cố

Installation failed

Sửa màn hình Installation failed bằng cách chuẩn bị Windows Security, tải trình cài đặt sạch, kết nối Cloudflare One Client, rồi chạy lại RealSetup.exe.

Hướng dẫn

Before you start

Tất cả hướng dẫn

Real-time protection chỉ tắt trong lúc cài đặt, và Smart App Control được tắt nếu nó chặn RealSetup.exe.

Cloudflare One Client đã kết nối ở Private browsing với Traffic and DNS (UDP) trước khi chạy RealSetup.exe.

Trình cài đặt đã được tải lại từ projectreal.gg sau khi kết nối Cloudflare One Client.

Khắc phục sự cố

Các bước

01Xác nhận lỗi cài đặt

Nếu Real hiển thị Installation failed và báo không thể thiết lập kết nối an toàn, trình cài đặt thường bị router, ISP, antivirus hoặc một đường mạng bị lọc chặn. Hãy bắt đầu sạch thay vì bấm lại cùng một trình cài đặt.

02Chuẩn bị Windows Security

Mở Windows Security. Tắt real-time protection trong lúc cài đặt. Sau đó mở Smart App Control và tắt nếu Windows chặn RealSetup.exe. Bật lại bảo vệ sau khi Real mở thành công.

03Tải RealSetup.exe sạch

Xóa các file RealSetup cũ khỏi Downloads. Mở trang Download Real chính thức và tải RealSetup.exe mới. Không dùng lại file cài đặt đã từng lỗi.

04Cho phép tải xuống trong trình duyệt

Nếu trình duyệt chặn file, mở Downloads từ menu trình duyệt hoặc nhấn Ctrl + J. Chọn keep, allow hoặc Download unverified file chỉ cho file RealSetup.exe từ projectreal.gg.

05Cài Cloudflare One Client

Tải Cloudflare One Client và chạy setup. Khi được hỏi mục đích sử dụng, chọn Private browsing. Việc này chuẩn bị đường mạng sạch trước khi trình cài đặt liên hệ dịch vụ Real.

06Kết nối trước khi mở RealSetup.exe

Chọn Traffic and DNS (UDP), rồi nhấn Connect. Chờ đến khi Cloudflare One Client hiển thị Connected. Giữ kết nối trong lúc chạy RealSetup.exe.

07Chạy lại RealSetup.exe

Mở RealSetup.exe mới sau khi Cloudflare One Client đã kết nối. Nếu Windows hiển thị cảnh báo, chỉ chọn run anyway cho file chính thức. Nhấn nút Download màu xanh và chờ Real mở.

Hướng dẫn

Hướng dẫn liên quan

Khắc phục sự cố injection Sửa các lỗi injection thường gặp: local auth before attach, timeout 20 giây và Roblox đóng sau injection. Làm theo từng bước theo đúng thứ tự. Real mở nhưng không hiển thị Đóng tiến trình Real bị kẹt trong Task Manager, sau đó mở Real lại. Lỗi kết nối bảo mật khi tải xuống Sửa ERR_SSL_PROTOCOL_ERROR trên máy chủ tải xuống bằng cách kết nối Cloudflare One Client trước khi mở lại trang tải.
