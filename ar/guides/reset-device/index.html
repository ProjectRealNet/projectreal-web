كل الأدلة

الأدلة

إعادة ضبط الجهاز أو HWID

انقل حساب Real إلى PC آخر أو امسح ربط الجهاز الحالي بدون الخلط بينه وبين Roblox HWID Spoofer.

الأدلة

Before you start

كل الأدلة

استخدم حساب Real الصحيح قبل إعادة ضبط أي جهاز.

أعد الضبط فقط عند تغيير الجهاز أو عندما يمنع Real تسجيل الدخول بسبب جهاز آخر مرتبط.

إذا كان cooldown نشطا، انتظر حتى يسمح Dashboard أو صفحة reset في المتصفح بإعادة ضبط أخرى.

الأدلة

الخطوات

01إعادة الضبط من Dashboard

سجل الدخول في الموقع، افتح تبويب Devices في Dashboard، واحذف ربط الجهاز الذي لم تعد تستخدمه. يمكن ربط حساب Real بجهاز واحد فقط في نفس الوقت. بعد إزالة الربط، افتح Real على PC الجديد وسجل الدخول مرة أخرى.

02إعادة الضبط أثناء login في app

إذا كان حسابك مرتبطا بالجهاز 1 وحاولت تسجيل الدخول على الجهاز 2، يفتح Real مسار browser login ويعرض تلقائيا شاشة reset للجهاز. اضغط Reset device هناك، ثم تابع تسجيل الدخول على الجهاز الجديد.

03احترم cooldown

Device reset يتحكم به cooldown الخاص بخطتك ولا يمكن تخطيه. استخدمه فقط عند تغيير PC، أو إعادة تثبيت Windows، أو عندما يقول Real إن الحساب مرتبط بجهاز آخر. هذا مختلف عن Roblox HWID Spoofer.

الأدلة

أدلة مشابهة

Installation ثبّت Real مع تجهيز Windows Security بشكل صحيح، وتوفير runtimes المطلوبة على Windows، واستخدام RealSetup.exe الرسمي، والتعامل مع فحوصات تنزيل المتصفح عند ظهورها. Create a Real account أنشئ حساب Real باستخدام Discord أو البريد الإلكتروني. اختر طريقة واحدة، واتبع خطواتها فقط، ثم فعّل الحساب قبل استخدام Real. ربط Discord اربط Discord بحساب Real موجود حتى يتم تعيين دور Real User والوصول إلى الدعم بشكل صحيح.
