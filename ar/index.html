حمّل لـ Windows

الأدلة

تعلّم Real بشكل أسرع.

عرض الأدلة
الأدلة Installation ثبّت Real مع تجهيز Windows Security بشكل صحيح، وتوفير runtimes المطلوبة على Windows، واستخدام RealSetup.exe الرسمي، والتعامل مع فحوصات تنزيل المتصفح عند ظهورها. الأدلة استخدام Real شغل إصدار Roblox المدعوم، اعمل inject من Editor، ثم شغل scripts من Script Hub أو من كودك الخاص. الأدلة شراء license اشتر Plus أو Pro من reseller موثق، واستلم license key، ثم فعله على حساب Real الصحيح.

الأسئلة الشائعة

الأسئلة المتكررة

هل Real مجاني؟

نعم. يمكنك استخدام Real بمفاتيح مجانية يومية. مفاتيح Plus وPro هي وصول مدفوع اختياري من بائعين موثوقين، بدون خطوات إعلانية ومع مزايا إضافية.

من أين أحمل Real؟

استخدم صفحة التنزيل الرسمية على projectreal.gg. تجنب المثبتات المعاد رفعها أو الأرشيفات المعدلة أو الملفات المرسلة عبر الرسائل الخاصة.

كيف يعمل Plus وPro؟

يتم تفعيل Plus وPro بمفاتيح ترخيص وليس باشتراكات. تضيف وقت وصول وتفتح مزايا الخطة على حساب Real الذي تفعّلها عليه.

هل يمكنني استخدام Real على كمبيوتر جديد؟

نعم. أعد ضبط الجهاز القديم من Dashboard أو أثناء تسجيل الدخول إلى التطبيق، ثم سجّل الدخول على الكمبيوتر الجديد. فترات انتظار إعادة ضبط الجهاز تعتمد على خطتك.

لماذا يحظر Windows المثبت؟

قد يعرض أمان Windows أو المتصفح تحذيرًا بشأن المثبتات المحمية. يشرح دليل التثبيت كيفية تجهيز Windows Security والاحتفاظ بملف RealSetup.exe الرسمي.

أين أحصل على الدعم؟

انضم إلى Discord الخاص بـ Real، واربط حسابك عند الحاجة، وافتح تذكرة دعم مع لقطات شاشة أو سجلات حتى يساعدك الفريق بشكل أسرع.
