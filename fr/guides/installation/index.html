Guides

Installation

Installez Real avec la bonne preparation de Securite Windows, les runtimes Windows requises, le RealSetup.exe officiel et les controles de telechargement du navigateur qui peuvent apparaitre.

Guides

Before you start

Tous les guides

Temporarily disable Microsoft Defender real-time protection before starting RealSetup.exe.

Temporarily disable Smart App Control if Windows Security blocks the installer.

Microsoft Visual C++ 2015-2022 x64, .NET 8 Desktop Runtime et Microsoft Edge WebView2 Runtime sont requis pour lancer et utiliser Real.

Guides

Étapes

01Temporarily prepare Windows Security

Ouvre d abord Securite Windows. Va dans Protection contre les virus et menaces et desactive la protection en temps reel pour l installation. Ouvre ensuite Controle des applications et du navigateur, va dans Smart App Control et desactive le si RealSetup est bloque. Tu peux reactiver ces reglages apres l ouverture de Real.

02Download RealSetup.exe

Open Download Real. Free users must complete the Work.ink or LootLabs ad steps first. At the end you receive RealSetup.exe. If the file name has extra random letters or numbers after RealSetup, that is normal and comes from our protected single-use download flow.

03Autoriser le telechargement bloque par le navigateur

Après le début du téléchargement, ton navigateur peut bloquer RealSetup.exe. Ouvre l'historique des téléchargements depuis le menu du navigateur ou appuie sur Ctrl + J. Ensuite, choisis conserver, autoriser ou Download unverified file pour le fichier venant de projectreal.gg.

04Ouvrir RealSetup.exe

Lance RealSetup.exe. Si Windows affiche un avertissement a l ouverture du fichier setup, choisis run anyway uniquement pour le fichier RealSetup telecharge depuis projectreal.gg. Quand l installateur est ouvert, appuie sur le bouton bleu Download et attends que Real s ouvre automatiquement.

05Turn protection back on

After Real has opened successfully, turn Microsoft Defender real-time protection and Smart App Control back on. If setup fails after pressing Download, follow the Installation failed troubleshooting article instead of repeating the same setup file.
