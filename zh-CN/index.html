FAQ

常见问题

Real 免费吗？

是的。你可以使用每日免费 key。Plus 和 Pro key 是来自认证经销商的可选付费访问，无广告步骤，并包含额外权益。

在哪里下载 Real？

请使用 projectreal.gg 上的官方 Download 页面。避免使用重新上传的安装程序、修改过的压缩包或私信发送的文件。

Plus 和 Pro 如何运作？

Plus 和 Pro 通过 license key 兑换，不是订阅。它们会为兑换的 Real 账户增加访问时间并解锁对应计划权益。

我可以在新电脑上使用 Real 吗？

可以。先在 Dashboard 或应用登录时重置旧设备，然后在新电脑登录。设备重置冷却时间取决于你的计划。

为什么 Windows 会阻止安装程序？

Windows 或浏览器安全功能可能会对受保护的安装程序发出警告。安装指南会说明如何准备 Windows Security 并保留官方 RealSetup.exe。

在哪里获得支持？

加入 Real Discord，需要时关联你的账户，并提交带截图或日志的支持工单，这样团队可以更快帮助你。
