指南

Installation

按照正确的 Windows Security 准备步骤、所需的 Windows 运行时、官方 RealSetup.exe 以及浏览器可能出现的下载确认来安装 Real。

指南

Before you start

所有指南

Temporarily disable Microsoft Defender real-time protection before starting RealSetup.exe.

Temporarily disable Smart App Control if Windows Security blocks the installer.

运行和使用 Real 需要 Microsoft Visual C++ 2015-2022 x64、.NET 8 Desktop Runtime 和 Microsoft Edge WebView2 Runtime。

指南

步骤

1.Temporarily prepare Windows Security

先打开 Windows Security。进入 Virus and threat protection，在安装期间关闭 real-time protection。然后打开 App and browser control，进入 Smart App Control，如果它阻止 RealSetup，就将其关闭。Real 成功打开后，可以重新开启这些设置。

2.Download RealSetup.exe

Open Download Real. Free users must complete the Work.ink or LootLabs ad steps first. At the end you receive RealSetup.exe. If the file name has extra random letters or numbers after RealSetup, that is normal and comes from our protected single-use download flow.

3.允许被浏览器阻止的下载

下载开始后，浏览器可能会阻止 RealSetup.exe。通过浏览器菜单打开下载历史记录，或按 Ctrl + J。然后对来自 projectreal.gg 的文件选择保留、允许或 Download unverified file。

4.打开 RealSetup.exe

运行 RealSetup.exe。如果 Windows 在打开 setup 文件时显示警告，只对从 projectreal.gg 下载的 RealSetup 选择 run anyway。安装器打开后，按蓝色 Download 按钮，等待 Real 自动打开。

5.Turn protection back on

After Real has opened successfully, turn Microsoft Defender real-time protection and Smart App Control back on. If setup fails after pressing Download, follow the Installation failed troubleshooting article instead of repeating the same setup file.
