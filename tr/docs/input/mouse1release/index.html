Giriş

mouse1release

Roblox window active oldugunda left mouse up event gonderir.

Söz dizimi

mouse1release()

Açıklama

Roblox window active oldugunda left mouse up event gonderir. Real, the requested mouse action ile ve movement ya da wheel data olmadan mouse input cagirir. Function arguments almaz, bir sey dondurmez, eslesen left mouse down event gondermez ve isrbxactive false olacaksa input gondermeden doner.

Parametresiz cagir. Fonksiyon gerekli contexti mevcut runtime durumundan okur.

Veri dondurmez. Cagriyi bir aksiyon olarak ele al ve gerekiyorsa hatalari cagri noktasinda yakala.

Örnek

Yer tutucu degerlerle ornek cagri.

mouse1release()
Önceki fonksiyon mouse1press Sonraki fonksiyon mouse2click
