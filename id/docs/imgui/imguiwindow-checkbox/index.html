ImGui

ImGuiWindow.Checkbox

Appends a checkbox element to an ImGuiWindow.

Sintaks

ImGuiWindow.Checkbox(window: ImGuiWindow, label: string, checked: any, onChange: function): ImGuiWindow

Argumen

NamaTipeDeskripsi
windowImGuiWindowImGuiWindow object returned by imgui.create. A destroyed or invalid window raises a Lua error.
labelstringCheckbox label string passed to the rendered ImGui checkbox.
checkedanyInitial checked value. nil and false are treated as false; other values are treated as true.
onChangefunctionFunction stored for this checkbox and invoked with the new boolean state after a change event is processed.

Return

NamaTipeDeskripsi
windowImGuiWindowThe same ImGuiWindow object, allowing chained method calls.

Deskripsi

Appends a checkbox element to an ImGuiWindow. The callback is invoked with the new boolean value when the checkbox changes, and the method returns the same ImGuiWindow object.

Panggil dengan 4 parameter: window, label, checked, onChange. Tabel argumen menjelaskan nilai wajib dan nilai yang hanya menyempurnakan perilaku.

Mengembalikan window (ImGuiWindow). Gunakan tabel returns untuk memisahkan nilai sukses, hasil nil, dan error yang bisa dipulihkan.

Contoh

Contoh pemanggilan dengan nilai placeholder.

local result = ImGuiWindow.Checkbox(nil, "example", nil, function() end)
print(result)

Tipe

ImGuiWindow

Pegangan dikembalikan oleh imgui.create. Metode pembuatan kontrol mengembalikan pegangan yang sama sehingga panggilan dapat dirangkai.

Button (label: string, onClick: () -> ()) -> ImGuiWindow Menambahkan tombol dan memanggil panggilan balik setelah klik.Checkbox (label: string, checked: any, onChange: (boolean) -> ()) -> ImGuiWindow Menambahkan kotak centang yang diinisialisasi ke status yang disediakan.CollapsingHeader (label: string, content: (ImGuiWindow) -> ()) -> ImGuiWindow Kontrol grup ditambahkan oleh callback konten di bawah header yang diciutkan.ColorPicker (label: string, red: number?, green: number?, blue: number?, alpha: number?, onChange: (number, number, number, number) -> ()) -> ImGuiWindow Menambahkan editor RGBA; menghilangkan komponen warna default ke 1.0.InputText (label: string, text: string?, onChange: (string) -> ()) -> ImGuiWindow Menambahkan input teks satu baris; menghilangkan default teks awal ke string kosong.SameLine () -> ImGuiWindow Tempatkan kontrol berikutnya pada baris yang sama.Separator () -> ImGuiWindow Menambahkan pemisah horizontal.SliderFloat (label: string, value: number, minimum: number, maximum: number, onChange: (number) -> ()) -> ImGuiWindow Menambahkan penggeser titik mengambang.SliderInt (label: string, value: integer, minimum: integer, maximum: integer, onChange: (number) -> ()) -> ImGuiWindow Menambahkan penggeser bilangan bulat.Text (text: string) -> ImGuiWindow Menambahkan teks non-interaktif.destroy () -> () Menghapus jendela dan melepaskan panggilan balik terdaftarnya.
Fungsi sebelumnya ImGuiWindow.Button Fungsi berikutnya ImGuiWindow.CollapsingHeader
