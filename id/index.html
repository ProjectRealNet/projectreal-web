Lihat panduan
Panduan Installation Instal Real dengan persiapan Windows Security yang benar, runtime Windows yang dibutuhkan, RealSetup.exe resmi, dan pemeriksaan unduhan browser yang mungkin muncul. FAQ

Pertanyaan umum

Apakah Real gratis?

Ya. Kamu bisa memakai Real dengan key gratis harian. Key Plus dan Pro adalah akses berbayar opsional dari reseller terverifikasi, tanpa langkah iklan dan dengan benefit ekstra.

Di mana saya mengunduh Real?

Gunakan halaman Download resmi di projectreal.gg. Hindari installer yang diunggah ulang, arsip yang dimodifikasi, atau file yang dikirim lewat pesan langsung.

Bagaimana Plus dan Pro bekerja?

Plus dan Pro ditukarkan dengan license key, bukan langganan. Keduanya menambah waktu akses dan membuka benefit plan pada akun Real tempat kamu menukarkannya.

Bisakah saya memakai Real di PC baru?

Bisa. Reset perangkat lama dari Dashboard atau saat login app, lalu masuk di PC baru. Cooldown reset perangkat bergantung pada plan kamu.

Mengapa Windows memblokir installer?

Keamanan Windows atau browser bisa memberi peringatan pada installer terlindungi. Panduan instalasi menjelaskan cara menyiapkan Windows Security dan tetap memakai RealSetup.exe resmi.

Di mana saya mendapat bantuan?

Masuk ke Discord Real, hubungkan akun jika diperlukan, lalu buka support ticket dengan screenshot atau log agar tim bisa membantu lebih cepat.
