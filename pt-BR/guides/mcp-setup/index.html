Configurar o Real MCP

Conecte o Real ao Claude Code, Claude Desktop, Cursor, Codex, Grok, Antigravity, Gemini CLI, OpenCode, LM Studio, OpenClaw ou ZCode para sua IA trabalhar com um cliente Roblox injetado.

Guias

Before you start

Todos os guias

O Real esta instalado, voce esta conectado e o cliente de IA que quer usar ja esta instalado.

Para ferramentas dentro do jogo, o Roblox foi iniciado pelo Real, injetado e está dentro de um jogo.

O cliente de IA foi reiniciado ou aberto como uma nova sessão depois da configuração.

Guias

Etapas

1.Iniciar o Real MCP

Abra Real -> Settings -> Connections. No cartão Real MCP, pressione Start. Mantenha o Real aberto enquanto usa o conector.

2.Conectar seu cliente de IA

Instale primeiro o cliente de IA que voce quer usar. Quando o Real MCP mostrar Running, pressione Set up ao lado do cliente detectado pelo Real. O Real oferece suporte a Claude Code, Claude Desktop, Cursor, Codex, Grok, Antigravity, Gemini CLI, OpenCode, LM Studio, OpenClaw e ZCode. Reinicie esse cliente de IA ou abra uma nova sessao para carregar a configuracao MCP.

3.Injetar e entrar em um jogo

A maioria das ferramentas do Real MCP precisa do Roblox iniciado pelo Real, injetado e dentro de um jogo. Diagnostics, files, search API, open script e launch Roblox podem funcionar apenas com o Real.

4.Verificar a conexão

Pergunte ao cliente de IA se ele está conectado ao Real MCP connector. Uma configuração correta consegue pingar o servidor e mostrar detalhes do cliente injetado.

Guias

Guias relacionados

Installation Instale o Real com a preparacao correta do Windows Security, as runtimes do Windows necessarias, o RealSetup.exe oficial e as verificacoes de download do navegador que podem aparecer. Create a Real account Crie sua conta Real com Discord ou email. Escolha um metodo, siga somente as etapas correspondentes e verifique a conta antes de usar o Real. Vincular Discord Conecte o Discord a uma conta Real existente para que o cargo Real User e o acesso ao suporte sejam atribuídos corretamente.
