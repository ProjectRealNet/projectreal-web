Multi Instance

Open multiple Roblox clients and run scripts on the accounts you choose.

Guides

Before you start

All guides

Use a separate Roblox account for every client.

Use the Roblox version marked Supported before injecting.

Inject only the clients you want to receive scripts.

Guides

Steps

01Enable Multi Roblox

Open Account Manager -> Options and turn on Multi Roblox. Keep Join Delay enabled or set a small delay if you start many accounts at once.

02Add Roblox accounts

Add every Roblox account you want to use. Multi Instance needs separate Roblox accounts, not the same account opened twice.

03Create a group and launch all

Open Multi Launch, create a group with the accounts you want, choose the game, and press Launch all.

04Choose the supported Roblox version

When Real asks which Roblox version to use, choose the version marked Supported. Wait until every Roblox client has joined the game.

05Press Inject

Open the Editor Tab and press Inject. Real opens the Clients panel so you can decide which running Roblox clients should be injected.

06Inject the clients you need

In the Clients panel, press Inject for each Roblox account you want to use. Keep Execute target enabled on the clients that should receive scripts.

07Check the injected status

Wait until every selected client shows Injected. If one client stays not injected, fix that client before running scripts on all accounts.

08Find and execute a script

Open Script Hub, pick a script, and press Execute. You can also paste your own script in the Editor Tab and execute it from there.

09Confirm the result in Roblox

Both injected clients should show the script result in Roblox. If only one client responds, check the Clients panel and the execute targets again.
