FAQ

คำถามที่พบบ่อย

Real ใช้ฟรีไหม?

ใช่ คุณใช้ Real ได้ด้วยคีย์ฟรีรายวัน ส่วนคีย์ Plus และ Pro เป็นการเข้าถึงแบบชำระเงินทางเลือกจาก reseller ที่ยืนยันแล้ว ไม่มีขั้นตอนโฆษณาและมีสิทธิพิเศษเพิ่ม

ดาวน์โหลด Real ได้จากที่ไหน?

ใช้หน้า Download ทางการบน projectreal.gg หลีกเลี่ยงตัวติดตั้งที่อัปโหลดซ้ำ ไฟล์ที่ถูกแก้ไข หรือไฟล์ที่ส่งมาทางข้อความส่วนตัว

Plus และ Pro ทำงานอย่างไร?

Plus และ Pro ใช้ license key แลก ไม่ใช่ subscription โดยจะเพิ่มเวลาเข้าถึงและปลดล็อกสิทธิ์ของแผนบนบัญชี Real ที่คุณแลกคีย์

ใช้ Real บน PC เครื่องใหม่ได้ไหม?

ได้ รีเซ็ตอุปกรณ์เก่าจาก Dashboard หรือระหว่างล็อกอินแอป จากนั้นเข้าสู่ระบบบน PC เครื่องใหม่ ระยะ cooldown รีเซ็ตอุปกรณ์ขึ้นอยู่กับแผนของคุณ

ทำไม Windows ถึงบล็อกตัวติดตั้ง?

ระบบความปลอดภัยของ Windows หรือเบราว์เซอร์อาจเตือนเกี่ยวกับตัวติดตั้งที่มีการป้องกัน คู่มือติดตั้งจะอธิบายวิธีเตรียม Windows Security และเก็บ RealSetup.exe ทางการไว้

รับการสนับสนุนได้ที่ไหน?

เข้าร่วม Real Discord ลิงก์บัญชีเมื่อจำเป็น แล้วเปิด support ticket พร้อมภาพหน้าจอหรือ logs เพื่อให้ทีมช่วยได้เร็วขึ้น
