Instancje

getinstances

Zwraca nowa array table zawierajaca kazdy object value obecnie zapisany w Instance cache.

Składnia

getinstances(): { Instance }

Zwroty

NazwaTypOpis
instances{ Instance }Array table wartosci object values skopiowanych z Instance cache table.

Opis

Zwraca nowa array table zawierajaca kazdy object value obecnie zapisany w Instance cache. Function nie przyjmuje arguments. Nie filtruje wedlug Parent, ClassName, DataModel fieldship, nil-parent state ani Instance validity poza sprawdzeniem, ze kazdy registry value jest object. Entries sa kopiowane do zwracanej tabeli pod sequential numeric indexes zaczynajac od 1. iteration order pochodzi z table iteration po cache i nie jest sortowany przez function.

Wywolaj bez parametrow. Funkcja czyta potrzebny kontekst z aktualnego stanu runtime.

Zwraca instances ({ Instance }). Uzyj tabeli zwrotow, aby oddzielic wartosci sukcesu, wyniki nil i bledy do obsluzenia.

Przykład

Przykladowe wywolanie z wartosciami zastepczymi.

local result = getinstances()
print(result)
