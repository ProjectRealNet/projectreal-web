Rozwiązywanie problemów

Błąd bezpiecznego połączenia podczas pobierania

Napraw ERR_SSL_PROTOCOL_ERROR na hoście pobierania, łącząc Cloudflare One Client przed ponownym otwarciem pobierania.

Poradniki

Before you start

Wszystkie poradniki

Błąd przeglądarki występuje na hoście pobierania Real, a nie na losowym mirrorze.

Cloudflare One Client jest połączony w trybie Private browsing z Traffic and DNS (UDP).

Download Real został otwarty ponownie po tym, jak Cloudflare One Client pokazał Connected.

Rozwiązywanie problemów

Kroki

01Potwierdź błąd przeglądarki

Jeśli przeglądarka pokazuje This site cannot provide a secure connection dla download.projectreal.live oraz ERR_SSL_PROTOCOL_ERROR, twoja ścieżka sieciowa blokuje lub psuje bezpieczne połączenie pobierania.

02Zainstaluj Cloudflare One Client

Pobierz Cloudflare One Client i uruchom instalator Windows. Użyj oficjalnej strony pobierania Cloudflare i pozostaw instalator otwarty do końca setupu.

03Połącz przez Traffic and DNS

Wybierz Private browsing, wybierz Traffic and DNS (UDP), a potem naciśnij Connect. Poczekaj, aż Cloudflare One Client pokaże Connected, zanim wrócisz do przeglądarki.

04Otwórz Download Real ponownie

Wróć do Download Real, odśwież stronę i rozpocznij pobieranie ponownie, gdy Cloudflare One Client pozostaje połączony. Jeśli przeglądarka potem zablokuje plik, zachowaj lub zezwól tylko na oficjalny RealSetup.exe z projectreal.gg.

Poradniki

Powiązane poradniki

Rozwiązywanie problemów z injection Napraw typowe błędy injection: local auth before attach, timeout po 20 sekundach i zamykanie Roblox po injection. Wykonaj kroki po kolei. Real otwiera się, ale nie jest widoczny Zamknij zablokowany proces Real w Menedżerze zadań, a potem otwórz Real ponownie. Installation failed Napraw ekran Installation failed, przygotowując Zabezpieczenia Windows, pobierając czysty instalator, łącząc Cloudflare One Client, a potem uruchamiając RealSetup.exe ponownie.
